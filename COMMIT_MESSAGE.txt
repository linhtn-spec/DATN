## Summary
Removed all hardcoded configuration values from the codebase and migrated to 
environment variables for better security and flexibility across different 
deployment environments (dev, staging, production).

## Changes

### Backend (server-shop/)
- app.js: Session secret from ENV (SESSION_SECRET)
- elastic_search/elastic_search.js: ES credentials from ENV
- form_mail/order_form.js: Frontend URL from ENV (FRONTEND_URL)
- form_mail/forget_password.js: Frontend URLs from ENV
- router/user_router.js: OAuth redirects from ENV (FRONTEND_URL)
- .env: Created with all required configuration variables
- .env.example: Created as template

### Frontend (frontend/)
- src/request/api.js: API base URL from ENV (VITE_API_BASE_URL)
- src/views/authentication/login/login.jsx: Socket endpoint from ENV
- src/views/admin/page/chat/SupportChat.jsx: Socket endpoint from ENV
- src/views/client/page/ChatWidget/ChatWidget.jsx: Socket endpoint from ENV
- .env: Created with Vite configuration
- .env.example: Created as template

### Documentation
- ENVIRONMENT_VARIABLES.md: Complete guide for env vars

- SUMMARY_HARDCODED_REMOVAL.md: Quick reference
